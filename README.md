# Forma

A minimal, polished habit-tracking web application.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Product documents

Project instructions, product requirements, and the current module live in the numbered Markdown files in the repository root.
